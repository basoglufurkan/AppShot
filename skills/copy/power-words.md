# Power words and benefit verbs

Power words don't convert by themselves. They sharpen a specific benefit. Use these lists to replace a weak verb or a vague adjective in a draft, never to decorate one. **One power word per headline;** the rest should be concrete nouns from the app's world.

## Speed

| Verb | Power words |
|---|---|
| finish | instantly |
| skip | one tap |
| get done | real-time |
| jump straight to | on the spot |
| speed up | no waiting |
| knock out (tasks) | shortcut |
| — | same-day |

- **Use for:** utilities, scanning, invoicing, editing, delivery, planning.
- **Watch out:** "in seconds" is on every listing; prefer a concrete unit (one photo, one sentence).

## Ease

| Verb | Power words |
|---|---|
| simplify | effortless |
| let it handle | automatic(ally) |
| sort | no setup |
| handle | guided, step by step |
| follow | ready-made |
| — | beginner-friendly |
| — | hands-free |

- **Use for:** onboarding-light apps, beginners, automation.
- **Watch out:** "easy" in more than one shot; say *what* is easy.

- **Use for:** finance, screen time, privacy, customisation, parental controls.

## Money

| Verb | Power words |
|---|---|
| save | every penny/cent |
| spend less | no hidden fees |
| split | free (only if true) |
| cancel (subscriptions) | one-time payment |
| avoid fees | ad-free |
| budget | payday |
| — | savings goal |

- **Use for:** budgeting, bill splitting, subscription trackers, shopping, deals.
- **Watch out:** "free" and promo words are restricted in Google Play graphics; keep them to the App Store set (`proof.md`). Return promises ("Earn 8%") are regulated financial claims.

## Health and wellbeing

| Verb | Power words |
|---|---|

| breathe | calm |
| move | balance |
| unwind | sound sleep |
| recover | strong |
| build (a habit) | gentle |
| nourish | consistent |

- **Use for:** sleep, meditation, fitness, nutrition, habits, cycle tracking.
- **Watch out:** medical verbs (cure, treat, heal) and weight-loss guarantees are legally risky in most markets. "Quiet your mind" is a cliché.

| Verb | Power words |
|---|---|
| protect | private |

- **Watch out:** every word here is a factual claim. Verify it in the code (encryption library, network calls, analytics SDKs) before using it.

## Overused words to avoid

They say nothing specific, appear on every competing listing, and some ("best", "#1") create legal exposure. Replace each with the concrete outcome, object or number it is hiding.

**English:** seamless, revolutionary, ultimate, powerful, innovative, next-level, game-changer, all-in-one (unless naming the things), best, amazing, awesome, magical, intuitive, user-friendly, easy-to-use, smart (as filler), unlock, elevate, supercharge, empower, journey, experience, solution, leverage, robust, cutting-edge, world-class, simply, effortlessly (more than once per set).

**Replacement examples:**
- "Powerful photo editor" → "Remove objects in **one tap**"
- "Seamless sync" → "Start on iPhone, finish on **iPad**"
