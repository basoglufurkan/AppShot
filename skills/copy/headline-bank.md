# Headline bank

A bank of 86 cross-niche patterns grouped by the job the user hires the app for. Each row has a pattern with `[slots]`, an English example and a Turkish example written natively (not translated). Use the bank when a draft is stuck, then run the result through `rewrite-drills.md`. Niche-specific lines live in `skills/niches/*.md`.

**Turkish slot-filling:** when you swap a word into a Turkish pattern, redo the suffix for vowel harmony and consonant changes (kitap → kitabını, liste → listeni, not "listeyini"). Put proper nouns and acronyms behind an apostrophe (YKS'ye, PDF'e), and keep the whole suffixed word inside the highlight.

## Notes on using the bank

- **Claims inside patterns are only allowed when true:** "encrypted", "backed up", "cheapest", "automatically", durations. Verify them per `proof.md`.
- **Swap the culture-bound slot per locale:** SAT → YKS, dollar → kuruş, "payday" → *maaş günü*. The locale files list the local equivalents.
- **One pattern per set** from each group, at most. Two rows from the same group in one set usually means two shots answer the same question (`sequence.md`).
